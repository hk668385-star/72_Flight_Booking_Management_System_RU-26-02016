Flight Booking Management System

Project Overview

A Python-based Flight Booking Management System developed using Object-Oriented Programming (OOP).

Features

- Load flight information from CSV files.
- Search flights by origin and destination.
- Book available flight seats.
- Calculate total booking fares.
- Generate unique booking IDs.
- Cancel bookings and restore available seats.
- Validate user inputs.

Technologies Used

- Python 3
- CSV Module
- Object-Oriented Programming
- Lists and Dictionaries
- Functions

Project Structure

- "main.py" – Main application/code.
- "flights.csv" – Flight information.
- "Testcase" - screenshots.

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run:

python main.py
